How to get an AWEAR API key

An API key is a private access code from AWEAR that lets MindTrail Lab retrieve your recordings.

  1. Open AWEAR’s portal. Use the Open AWEAR portal button below. It opens a separate tab, so you can return here afterward.
  2. Enter your email and click Continue. Follow AWEAR’s sign-in or account setup prompts. Use the account that has access to your recordings.
  3. Find API keys in the portal. Choose the option to create a new key and name it “MindTrail Lab”.
  4. Copy the key AWEAR displays. It is shown only once. Keep a private copy somewhere safe.
  5. Return to this MindTrail Lab tab. Paste the key into API key below and click Connect. Your recordings will start syncing automatically.
